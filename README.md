## Executive Summary

**Project Atlas** is an end-to-end, enterprise-grade **AI HR Analytics & Talent Retention Intelligence Platform** developed for **TechCorp India** (a 5,000-employee IT Services firm). 

Facing an unsustainable **25% annual employee attrition rate** costing **₹8.5 Crores annually** in replacement overhead, lost institutional knowledge, and billable project delays, Project Atlas transforms workforce management from **reactive crisis response** into **proactive, data-driven retention**.

### 💼 Business & Financial Highlights
* **Predictive Precision:** Supervised ML Ensemble (*XGBoost: 87.2% AUC-ROC*) providing a **90-day early warning window** prior to formal employee resignation.
* **Target Value Realization:** **40% reduction in avoidable turnover**, recovering **₹3.40 Crores** in recurring annual cash savings.
* **Financial Payback:** **1,682% Net 1st-Year ROI** on an initial ₹18.0 Lakh AI implementation investment with a **1.6-month capital amortization timeline**.
* **Live 24/7 Production Deployment:** Streamlit Community Cloud web application connected to high-performance **Groq LPU (LLaMA 3.3 70B)** with sub-second inference.

### 🔍 Explainable AI (SHAP Summary)
Using **SHAP (SHapley Additive exPlanations)**, we unlocked the model's black box:
1. **Mandatory Overtime** was the single highest driver of churn ($+25.4\%$ risk weight).
2. **Job Satisfaction $\le 2/4$** contributed an average $+22.1\%$ to attrition likelihood.
3. **Monthly Compensation $< ₹30,000$** constituted the leading flight risk for junior engineering staff.

* **Algorithmic Fairness Testing:** Regular disparate impact audits across Gender, Age, Department, and Region confirm all bias disparity scores remain below the strict **0.05 threshold** (Pass standard: $< 0.10$).
* **Human-in-the-Loop Oversight:** AI operates exclusively as a **decision-support recommender**; all final retention workflows require explicit human manager sign-off.

## 💻 Local Quickstart Installation

To run this application locally on your computer:

```bash
# 1. Clone the repository
git clone https://github.com/anushree-25-nag/project-atlas.git
cd project-atlas

# 2. Create and activate a virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Set your Groq API Key
export GROQ_API_KEY="your-groq-api-key-here"  # On Windows: set GROQ_API_KEY="your-key"

# 5. Launch the Streamlit application
streamlit run app.py
